# Интерпретатор AST

Программа принимает путь к JSON-файлу с AST и выполняет его. Значениями языка могут быть 32-битные целые числа, строки и изменяемые массивы. Сравнения и логические операции возвращают `0` или `1`, а в условиях ноль означает ложь и любое ненулевое значение — истину.

Поддерживаются узлы `const`, `string`, `array`, `elem`, `set`, `length`, `var`, `binop`, `read`, `write`, `assn`, `seq`, `if`, `while`, `do` и `skip`. `+` складывает числа и объединяет строки или массивы; сравнения строк и массивов лексикографические. Конструкции исходного языка `for`, `elif` и составные присваивания разворачиваются «мордочкой» в эти базовые узлы AST.

Сборка и тесты:

```shell
./gradlew clean test build
```

Запуск тестового AST:

```shell
./gradlew :app:run --args='test.json'
```

Пример суммы всех чисел в массиве произвольной вложенности находится в [`examples/nested_array_sum.json`](examples/nested_array_sum.json). Каждый элемент в нём представлен парой `[флаг, значение]`: `0` обозначает число, `1` — вложенный массив. Запуск примера выводит `15`:

```shell
./gradlew :app:run --args='examples/nested_array_sum.json'
```

## Тестовые программы

Каждый сквозной тест состоит из двух файлов с одинаковым именем:

- [`app/src/test/resources/programs`](app/src/test/resources/programs) содержит исходный код языка в файлах `.in`;
- [`app/src/test/resources/json`](app/src/test/resources/json) содержит соответствующий AST в файлах `.json`.

Входные данные и ожидаемый вывод записаны отдельными переменными `input` и `expectedOutput` непосредственно в [`InterpreterProgramTest.kt`](app/src/test/kotlin/InterpreterProgramTest.kt). Если одну программу нужно проверить на нескольких входах, для неё создаются несколько одинаково оформленных тестовых методов, использующих общую пару `.in`/`.json`.

Тестовый раннер проверяет наличие исходника, разбирает JSON настоящим `GetJsonToAST`, выполняет AST через `ExecutionVisitor`, сравнивает весь вывод и убеждается, что программа использовала все переданные входные значения.
