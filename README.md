# Интерпретатор AST

Программа принимает единственный аргумент — путь к JSON-файлу с AST — и выполняет его. Значения языка являются 32-битными целыми числами; сравнения и логические операции возвращают `0` или `1`, а в условиях ноль означает ложь и любое ненулевое значение — истину.

Поддерживаются узлы `const`, `var`, `binop`, `read`, `write`, `assn`, `seq`, `if`, `while`, `do` и `skip`. Конструкции исходного языка `for`, `elif` и составные присваивания разворачиваются «мордочкой» в эти базовые узлы AST.

Сборка и тесты:

```shell
./gradlew clean test build
```

Запуск тестового AST:

```shell
./gradlew :app:run --args='test.json'
```

## Тестовые программы

Каждый сквозной тест состоит из двух файлов с одинаковым именем:

- [`app/src/test/resources/programs`](app/src/test/resources/programs) содержит исходный код языка в файлах `.in`;
- [`app/src/test/resources/json`](app/src/test/resources/json) содержит соответствующий AST в файлах `.json`.

Входные данные и ожидаемый вывод записаны отдельными переменными `input` и `expectedOutput` непосредственно в [`InterpreterProgramTest.kt`](app/src/test/kotlin/InterpreterProgramTest.kt). Если одну программу нужно проверить на нескольких входах, для неё создаются несколько одинаково оформленных тестовых методов, использующих общую пару `.in`/`.json`.

Тестовый раннер проверяет наличие исходника, разбирает JSON настоящим `GetJsonToAST`, выполняет AST через `ExecutionVisitor`, сравнивает весь вывод и убеждается, что программа использовала все переданные входные значения.
